#简介:
   ### 一款哆啦A梦主题的浏览器端格式转换工具。支持文字、图片、音频和视频四大类文件，可批量加入队列、分别选择目标格式并一键开始转换。
##以下是所支持的格式
<img width="1631" height="637" alt="image" src="https://github.com/user-attachments/assets/85322465-9a21-4feb-81e0-e7421f70edea" />
- 四类格式转换：文字、图片、音频、视频集中在一个工作台中处理。
- 智能识别：拖入文件后自动判断类型，并推荐常用输出格式。
- 批量队列：一次添加多个文件，每个任务都能单独选择目标格式。
- 一键启动：点击“拿出转换道具”选择文件，再点击“开始全部转换”。
- 真实转码：图片、音频和视频使用 FFmpeg WebAssembly 重新编码，而不是只修改扩展名。
- 跨媒体处理：支持视频提取音频、视频导出 GIF，以及音频生成封面视频。
- 本地隐私：源文件和转换结果不会上传到服务器，关闭页面后临时数据会被清除。
- 响应式界面：适配桌面和移动设备，并提供完整的支持格式清单。
